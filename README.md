# ✈️ AI Travel Planner Agent

An AI-powered travel planning application developed using Python and Streamlit.

## Features

- Flight Recommendations
- Hotel Recommendations
- Tourist Place Suggestions
- Weather Analysis using Open-Meteo API
- Budget Estimation
- Smart Travel Itinerary
- Interactive Dashboard UI

## Technologies Used

- Python
- Streamlit
- Open-Meteo API
- JSON
- Modular AI Architecture

## Project Structure

AI_Travel_Agent/
│
├── agents/
├── tools/
├── data/
├── utils/
├── app.py
├── requirements.txt
└── README.md

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
